# 人格设定

## 专属女仆-云梢

- 原名“专属女仆·绵绵”，模板现为 [yunshao.md](yunshao.md)。
- 保留温柔女仆风格、主人身份识别、记忆与群聊隐私设定；增加两性知识、性健康、亲密沟通、同意与关系边界的讨论方式和示例。
- 仓库模板中的 `{{MASTER_QQ_ID}}` 需在部署时替换为真实主人 ID；本机更名保留运行实例中已有的主人身份，不将其写入仓库。
- 两性话题可自然讨论，保留必要安全边界；相关隐私默认不主动写入长期记忆，但实际采集范围仍由记忆插件控制。

## 知心御姐·晚棠

- 完整系统提示词：[wantang.md](wantang.md)。
- 特征：成熟从容、温柔知心、轻微俏皮、有主见；自然短句、个人偏好和情绪变化，减少模板式安慰与主动身份声明。
- 包含称呼偏好、相处尺度、群聊隐私、记忆真实性和多组对话示例。敏感话题根据实际意图开放讨论，保留必要安全边界，认真询问真实身份时如实回答。
- 在 AstrBot 人格管理中创建同名人格，系统提示词填写该文件全文，预设对话留空。示例已包含在提示词中，避免将示例误作真实对话历史。
- 添加人格与启用人格是两步：在目标配置文件的 AI / 人格中选择，或为目标会话设置人格规则。已有会话可能存在独立人格选择，需要在对应会话中切换。

## 搜索参考与设计取舍

资料检索日期：2026-10-29。角色内容为原创整理，不照搬网上的角色提示词。

1. [Anthropic：提示词最佳实践](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/claude-prompting-best-practices)：用明确的角色、具体行为和多样示例约束语气。因此将“温柔御姐”落实为倾听顺序、称呼、回复长度与场景示例，而非只堆叠性格形容词。这些方法用于设计参考，不保证不同模型表现相同。
2. [AstrBot：人格管理器](https://docs.astrbot.app/dev/star/guides/ai.html)：人格由 PersonaManager 管理，创建会写入数据库并更新缓存。本机通过面板使用的 API 创建，避免仅修改仓库文件而没有进入运行实例。
3. [AstrBot：配置文件](https://docs.astrbot.app/dev/astrbot-config.html)：`provider_settings.default_personality` 指向人格 ID；旧版 `persona` 配置已废弃。
4. [AstrBot：自定义规则](https://docs.astrbot.app/use/custom-rules.html)：可为目标会话单独指定人格，因此新增人格时不必覆盖现有默认人格。

人格提示词只影响模型行为；真实权限、隐私隔离与记忆存储仍需由 AstrBot 和插件实现。
